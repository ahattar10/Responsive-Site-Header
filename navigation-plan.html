Chosen breakpoint in relative units: 36em (about 576px), where the longer test label fit without wrapping; it wrapped at 516px.

Long-label and zoom retest: At 516px, the longer label wrapped; at 576px, it fit on one line. At 200% zoom with a 576px viewport, all five navigation links stayed on one row, page text wrapped, and the footer was reachable without horizontal scrolling. The original label was restored.

5. JavaScript code defense

The script selects the Menu button as button and the link list as list. It adds the nav-enhanced class only when both are present, then shows the button and starts aria-expanded at false. The named function setMenuOpen changes aria-expanded; the CSS uses that value to show or hide the links. A click checks the current value and toggles it. When Escape is pressed while the menu is open, the script closes it and returns focus to the button with button.focus().
